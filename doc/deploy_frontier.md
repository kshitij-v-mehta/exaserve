# Deploy ExaServe on Frontier

The complete, validated Frontier instructions, scale controls, compatibility
repairs, failure chronology, and troubleshooting guide are maintained in
[`scripts/frontier/README.md`](../scripts/frontier/README.md).

That guide supersedes the earlier ROCm 7.0/vLLM 0.14 wheel experiment. The
validated stack uses ROCm 7.1.1, PyTorch 2.10, and a vLLM 0.15 source build.
